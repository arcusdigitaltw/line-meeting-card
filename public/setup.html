設定精靈

所有需要的設定和金鑰都在這裡完成，不用改任何檔案。每一步都會存起來、存完立刻生效；最後一步會實際檢查一次，確認真的能用。

開始之前，請先看這一段

這個工具會把會議資訊做成可以轉傳的卡片，也可以派機器人進會議錄音、做逐字稿和摘要。

請不要未經公司允許，擅自用在公司的客戶會議上。
  • 客戶名單、會議內容、錄音與逐字稿，都有可能屬於公司的機密資產。
  • 在公司會議使用前，請先取得主管或公司的同意，並確認符合公司的資安與保密規定。
  • 機器人進會議會錄音。請事先告知所有與會者，並遵守當地的法規。
  • 逐字稿與摘要會存在你自己架的這台主機上，也會送到你設定的語音轉文字與 AI 服務。請自行評估能不能這樣處理。

設定後台密碼

之後進後台都要用這組密碼。請設一組別人猜不到的，至少 10 個字。

為了避免別人搶先幫你設密碼，設定碼只會顯示在你自己啟動程式的那個視窗裡，長得像「設定碼：123456」。

品牌與顯示

這些會出現在卡片、邀請頁和機器人的名字上。都有預設值，不確定的先不用改。

建議寫清楚是誰家的、來做什麼，與會者看到陌生帳號進來才不會緊張。

確認對外網址

卡片上的按鈕、LINE 的設定，都要用到你這個服務的網址，而且 LINE 只接受 https。

我先幫你填了現在瀏覽器上的網址。

你現在是用本機網址打開的
  • 只想先看看畫面、設好密碼：直接按下一步，之後再回來改。
  • 要真的分享到 LINE，需要一個 https 網址，下面兩種做法選一種。

還沒有 https 網址？兩種做法

下面的圖是照實際畫面畫的示意圖，實際畫面可能因改版略有不同。

    npx cloudflared tunnel --url http://localhost:3000
  2. 等幾秒，畫面上會出現一個框，裡面那個 https://….trycloudflare.com 就是你的對外網址：

    INF | https://random-words-here.trycloudflare.com |

    INF +--------------------------------------------------------+

  3. 把那個網址複製起來，貼到上面的「對外網址」，再改用那個網址重新打開這一頁（網址後面加 /setup.html）。這個視窗也要一直開著，關掉網址就失效。
做法 B　用自己的網域約 15 分鐘・免費・網址固定・需要網域已交給 Cloudflare 管理

綁定 LINE

要讓卡片能在 LINE 裡「選人傳送」，需要在 LINE Developers 建立一個 LIFF，再把它的 LIFF ID 貼回來。下面的圖是照 LINE 後台版面畫的示意圖，實際畫面可能因改版略有不同。

  1. 打開 LINE Developers Console，用你的 LINE 帳號登入，按 Create a new provider，名稱填公司或自己的名字。
    developers.line.biz/console
    ProvidersCreate
  2. 在 Provider 裡按 Create a new channel，類型選 LINE Login（不是 Messaging API，這裡最多人選錯）。App types 勾 Web app，其他照實填。
    LINE Login
    Messaging API
    LINE MINI App
  3. 進到剛建好的 channel，點上方的 LIFF 分頁，按 Add，照下面填：
    Basic settingsLINE LoginLIFFRoles
    LIFF app name會議資訊卡
    SizeTall
    Endpoint URLhttps://你的網址/share.html
    Scopes☑ openid　☑ profile
    Add friend optionOff
    Add

    Endpoint URL 請直接複製這一行（一個字都不能差）：

    —

    LIFF app name 不能包含「LINE」這個字。

  4. 建好之後，在這個 LIFF 的設定裡找到 Share target picker，把它打開。沒開的話，分享時不會跳出「選擇傳送對象」。
    Share target picker　On
  5. 把列表上的 LIFF ID 複製下來，貼到下面。它長得像 1234567890-AbCdEfGh。
    LIFF ID1234567890-AbCdEfGh
    LIFF URLhttps://liff.line.me/1234567890-AbCdEfGh
  6. 最後，把 channel 最上方的狀態從 Developing 改成 Published。還在 Developing 的時候，只有你自己打得開，朋友點連結會看到錯誤。（建議先自己測到會動，再改成 Published。）

AI 會後摘要（可以先跳過）

有填的話，會議結束後會自動整理重點、完整摘要與待辦事項。沒填就只保留逐字稿。

  1. 用 OpenAI 的話，到 platform.openai.com/api-keys 建立一組金鑰，貼到下面就好，其他兩欄不用動。
  2. 用其他相容 OpenAI 格式的服務（OpenRouter、自己架的 OneAPI 或 Ollama），把「API 網址」和「模型」改成對應的值。

　

最後檢查

每一項都實際試一次，確認精靈結束後真的能用。

    最後一關：用手機實際傳一張卡

    前面都是程式能替你檢查的。LINE 後台的三個設定（Endpoint URL、Share target picker、Published）只有實際傳一次才知道對不對。

    1. 按下面的按鈕，建立一場測試會議並複製分享連結。
    2. 把連結貼到 LINE 的任何聊天室（傳給自己的「Keep 筆記」最方便），用手機點開。
    3. 畫面跳出「選擇傳送對象」，選一個人傳送，對方收到卡片，就完成了。

    沒跳出選人畫面？分享頁下方的灰色小字會寫原因；最常見的是 Endpoint URL 和這裡的對外網址不一樣，或 Share target picker 沒打開。

    之後想改任何一項，隨時回到這一頁（後台右上角的「設定」）。
